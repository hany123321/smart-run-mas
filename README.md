# حسابات المهندس — SMART RUN

نظام إدارة حسابات المشاريع: المشاريع، المقبوضات، المصروفات، التصنيع والتركيب،
عروض الأسعار، الفواتير، وسابقة الأعمال.

---

## ⚠️ خطوات إلزامية قبل التشغيل

التطبيق دلوقتي بيستخدم **Firebase Authentication** لتسجيل الدخول.
من غير الخطوتين دول التطبيق **مش هيشتغل** وهيفضل واقف على شاشة الدخول.

### 1) تفعيل تسجيل الدخول

1. افتح [Firebase Console](https://console.firebase.google.com/) واختر مشروع `mas1-8dc5e`.
2. من القائمة الجانبية: **Build ← Authentication**، واضغط **Get started**.
3. تبويب **Sign-in method** ← اختر **Email/Password** ← فعّل **Enable** ← **Save**.
4. تبويب **Users** ← **Add user**:
   - **Email**: مثلاً `admin@smartrun.app`
   - **Password**: كلمة مرور قوية (8 حروف على الأقل، حروف وأرقام ورموز)
   - **Add user**

بعد كده تقدر تدخل بـ `admin` بس (من غير `@smartrun.app`) — التطبيق بيكمّل
النطاق تلقائياً. النطاق ده متظبط في `assets/config.js` تحت `AUTH_CONFIG.usernameDomain`.

> **مهم لخاصية "نسيت كلمة المرور":** رسالة الاستعادة بتتبعت على بريد حقيقي.
> لو استخدمت نطاق وهمي زي `smartrun.app` مش هتوصلك رسالة. عشان الخاصية دي
> تشتغل، سجّل الحساب ببريدك الحقيقي (Gmail مثلاً) وادخل بيه كامل.

### 2) نشر قواعد الأمان

1. **Build ← Firestore Database ← Rules**
2. امسح اللي موجود، والصق محتوى ملف [`firestore.rules`](firestore.rules)
3. **Publish**

من غير الخطوة دي أي حد على الإنترنت يقدر يمسح أو يعدّل كل حساباتك.

## 🔓 ملاحظة أمنية مهمة عن رابط المعرض

صفحة المعرض العام (`?portfolio=1`) بتفتح للعملاء من غير تسجيل دخول، وعشان
كده قواعد الأمان بتسمح بـ **القراءة** للجميع.

**معنى ذلك:** أي عميل معاه رابط المعرض يقدر يفتح أدوات المطوّر في المتصفح
ويقرأ **كل** بيانات التطبيق — المشاريع، الأرباح، أسماء العملاء، والفواتير.
الكتابة محمية، لكن القراءة لأ.

**لو حبيت تقفل التسريب ده لاحقاً:** لازم تنقل صور المعرض لمستند منفصل،
وبعدها تغيّر السطر في `firestore.rules` لـ `allow read: if request.auth != null;`

## 🚀 التشغيل

- **محلياً:** `python server.py` ثم افتح <http://127.0.0.1:5500/index.html>
- **على GitHub Pages:** بيتنشر تلقائياً مع كل push على `main`

> فتح `index.html` مباشرة كملف (`file://`) بيشتغل، لكن رابط المعرض للعملاء
> مش هيشتغل — لازم يكون منشور على استضافة.

## 📁 بنية المشروع

```
index.html              الهيكل والصفحات (HTML فقط)
assets/
  app.css               نظام التصميم كامل (داكن + فاتح)
  config.js             كل الإعدادات والثوابت — عدّل هنا
  util.js               أدوات مشتركة: esc، تنسيق، نوافذ، تنبيهات، سمة
  auth.js               تسجيل الدخول والخروج وحد المحاولات
  data.js               Firestore، المزامنة، سجل النشاط، ضغط الصور
  docs.js               عروض الأسعار والفواتير والمعرض والطباعة
  app.js                الصفحات والحسابات والرسوم البيانية
  logo.jpg              شعار الشركة
firestore.rules         قواعد الأمان — لازم تتنشر في Firebase Console
server.py               خادم تطوير محلي
```

## ⚙️ الإعدادات

عدّل [`assets/config.js`](assets/config.js) لتغيير:

| الإعداد | الوصف |
|---|---|
| `AUTH_CONFIG.usernameDomain` | النطاق اللي بيتضاف لاسم المستخدم |
| `AUTH_CONFIG.maxAttempts` | عدد المحاولات قبل الحظر المؤقت (افتراضي 5) |
| `AUTH_CONFIG.lockoutMs` | مدة الحظر (افتراضي 5 دقائق) |
| `APP_CONFIG.inactivityMs` | مدة الخمول قبل تسجيل الخروج التلقائي |
| `STORAGE_LIMITS` | حدود ضغط الصور وحجم المستند |

بيانات الشركة (الاسم، الهاتف، العنوان، العملة) بتتعدل من **صفحة الإعدادات**
داخل التطبيق نفسه.

## 💾 حدود التخزين

كل بيانات التطبيق في مستند Firestore واحد، وحده الأقصى **1 ميجابايت**.
الصور بتتضغط تلقائياً، والتطبيق بيعرض مؤشر المساحة في صفحة سابقة الأعمال
وبيمنع الحفظ قبل ما توصل للحد بدل ما يفشل فجأة.

لو المساحة قربت تخلص: امسح صور قديمة، أو انقل الصور لـ Firebase Storage.
